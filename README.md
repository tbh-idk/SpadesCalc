default view

capabilities
-
 * counts points for tricks and bag (10*bid + extra)
   * based on total bids, not per player
 * deducts 10*bid for unsuccessful bids
 * deducts 100 points for going over 10 bags
 * rewards 100 points for successful nil bids
 * deducts 100 points for failed nil bids

current limitations:
-
 * does not validate the the number if tricks taken sums to 13
 * no undo or reset
